Integer Overflow Explorer
This project is a single file browser app that teaches about integer overflow. 

Contents
Choose bit width, signed or unsigned and operation of choice. 
Enter values for A and B. 
Visualize A, B, and the stored value as bits. 
See the true math result versus what the computer stores. 
There are also some one click presets that are common teaching points for integer overflow. 

How to run it
No build step and no dependencies. Open index.html in any browser. 

Built with 
AI-assisted development using Claude, then reviewed and tested by hand.
