Reflection
I built this one page integer overflow visualizer to help visualize when integer overflow occurs. When building the project I knew I wanted to do integer overflow and I prompted AI for help in creating the page. I wanted something simple and easy to understand. I think one thing I learned is that overflow does not just occur because a number gets too big. There can be subtraction that also causes overflow which in part I knew but visualising that helped me. I think this page really just helped me to see when overflow can occur because I think it is hard to visualize it in my brain but seeing it clearly written out and the number that gets stored to the computer is really helpful as well.
